# RSyntaxTextArea 演示程序（中文文档）

> 对应英文原文：[README.md](./README.md)

这是一组面向 [RSyntaxTextArea](https://github.com/bobbylight/RSyntaxTextArea) 的简单演示应用。

## 演示列表

### RSyntaxTextAreaDemoApp
一个简单的演示应用，展示多种语言的语法高亮与代码折叠能力，
同时允许在内置编辑器主题之间切换，并提供若干其他基础选项。

### FindAndReplaceDemo
一个**非常**基础的演示，展示内置的查找/替换功能。
如果想直接获得与 RSTA 集成的"查找和替换"对话框，请看姊妹项目
[RSTAUI](https://github.com/bobbylight/RSTAUI)。

### SyntaxSchemeDemo
展示如何修改所使用的字体与颜色。

## 运行

```bash
./gradlew RSyntaxTextAreaDemo:run
```
